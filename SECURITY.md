# Güvenlik Politikası (Security Policy)

MiBox Konsol güvenliği ciddiye alır. Cihazınızın sağlığını, kişisel verilerinizi ve ADB bağlantınızı korumak için komut onay filtreleri ve güvenlik mekanizmaları (`gate.py`, otomatik anlık yedekleme vb.) barındırır.

## Desteklenen Sürümler

| Sürüm | Destekleniyor mu? |
| :--- | :--- |
| 1.2.x | :white_check_mark: Evet |
| < 1.2 | :x: Hayır |

## Güvenlik Açığı Bildirimi

Eğer bu yazılımda bir güvenlik açığı tespit ederseniz:
- Lütfen bunu herkese açık GitHub Issue olarak bildirmeyin.
- Güvenlik bildirimini doğrudan proje yöneticisine iletin veya GitHub üzerinden "Report a vulnerability" seçeneğini kullanın.
- Bildirilen açıklar en kısa sürede incelenerek düzeltme güncellemesi yayınlanacaktır.
